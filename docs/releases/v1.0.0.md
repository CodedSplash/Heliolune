Первый публичный релиз Heliolune («Сутки») для Windows 11.

- Автоматическая смена светлых и тёмных обоев по двум настраиваемым границам суток.
- Выбор двух изображений или двух папок со случайной сменой обоев.
- Анимированная дневная и ночная шкала, компактные настройки и меню трея.
- Опциональный автозапуск при входе в Windows.

Скачайте `Heliolune-Windows.zip`, распакуйте его и запустите `Sutki.exe`. Программе нужен .NET Framework 4.8 или новее, а `Sutki.exe.config` должен лежать рядом с исполняемым файлом.

Контрольная сумма архива SHA-256 опубликована в `SHA256SUMS.txt`.
